# PixelProof v0.1.0-rc.2

Pre-release of the local-first visual feedback CLI for AI-generated web interfaces.

**Repository:** https://github.com/flower1201/pixelproof  
**npm package:** `pixelproof-cli` (CLI binary: `pixelproof`)  
**npm status:** Not published to npm.

## Features

- Image-to-image pixel comparison (Sharp normalize + pixelmatch)
- Local URL capture with Playwright Chromium (loopback hosts only)
- Diff regions and offline HTML report (Before/After, Overlay, Diff)
- `result.json` metrics and rule-based `fix-instructions.md` for coding agents
- Fail-fast on image dimension mismatch (no silent resize)

## Installation (from source)

```bash
git clone https://github.com/flower1201/pixelproof.git
cd pixelproof
npm install
npm run build
npx playwright install chromium   # only needed for --url
```

```bash
node dist/cli/index.js compare \
  --target ./design.png \
  --actual ./screenshot.png \
  --out ./pixelproof-report
```

After a future npm publish (not this release):

```bash
npm i -g pixelproof-cli
pixelproof compare --target ./design.png --actual ./shot.png --out ./pixelproof-report
```

## Requirements

- Node.js `^22.12.0 || ^24.0.0`
- npm
- Chromium via Playwright for `--url` mode

## Limitations

- `--url` accepts loopback hosts only (`localhost`, `127.0.0.1`, `[::1]`)
- Target and actual images must match dimensions exactly
- `mismatchRatio` / pixel match numbers measure pixel difference; they are **not** a design-quality score
